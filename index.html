Import from Fusion 360

Three ways in
Option 1 · Recommended

Run the export script

  1. Put a construction point at each hardpoint of one front corner and name it LBJ, UBJ, OTR, ITR, WC, CP. Add LCA_F, LCA_R, UCA_F, UCA_R for bump steer.
  2. Download export_hardpoints.py.
  3. In Fusion: Utilities → Add-Ins → Scripts and Add-Ins → Create → Script (Python), name it export_hardpoints, click Edit, and paste the file over the template.
  4. Run it, save the CSV, and drop it on this page.
Option 2

Hardpoint CSV or JSON

Any file with a name and X, Y, Z per row. Names are matched loosely, so Lower Ball Joint, lca_outer and LBJ all work. Scalar rows like wheelbase and tire_radius are read too.

Option 3

Fusion parameters CSV

If your hardpoints live as user parameters (for example LBJ_x, LBJ_y, LBJ_z), export them with a parameter CSV exporter and drop the file here. The Unit column is respected.

Axes: Fusion is often Y-up. Set the CAD forward and up axes above before importing, or after importing and click Re-read last file. A right-side corner is mirrored automatically.

Note: the car centerline should sit at CAD lateral = 0. Ground comes from the contact patch, or from the wheel center minus tire_radius.
