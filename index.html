Tire curve fitter · quick fit of your own data

Fits a simple Magic Formula (B, C, D, E, Sh, Sv) to lateral force vs slip angle, separately for each normal load. For the team's reference tyre (pressure, camber and load in one fitted model) use the TTC tyre model panel below.
Sample tire loaded (synthetic 10 in FSAE tire, clearly not real test data).
Fy = D·sin(C·atan(Bx − E(Bx − atan Bx))) + Sv,  x = α + Sh

CSV columns: slip angle (SA, deg or rad), lateral force (FY), and optionally normal load (FZ). TTC-style exports work. Loads are grouped automatically. Cα = B·C·D is the cornering stiffness at zero slip. μpeak = |D| / Fz.

How this differs from the team model: each load gets its own independent curve, and camber, pressure and aligning moment are ignored. Pressure and camber must be held constant within a file, or the fit mixes them. The sample tyre is synthetic. Use this to look at a new data set quickly; use the TTC model below for design numbers. See docs/TYRE_MODEL.md.

TTC tyre model · team reference tyre

Hoosier 18.0×6.0-10 R20 fitted in MATLAB to TTC Round 9 data: one Magic Formula model with load, camber and pressure terms, plus aligning moment and a loaded-radius fit.

Load the team package (Load team package, top right) to use the fitted TTC model. Its coefficients are not stored on this public site because TTC data-use terms restrict sharing the data outside member teams. See docs/TEAM_PACKAGE.md.

Steering effort

Static (parking) and cornering effort at the rim, against the team targets of 5 N·m ideal and 10 N·m maximum.

Static torque per wheel uses T = Fz·μ·√(B²/8 + e²), from the Static Steering Effort paper on the team drive, with scrub e from the hardpoints. Cornering torque uses (mechanical + pneumatic trail)·Fy on each front tire, with loads from the load transfer tool. Both are carried to the rim through the linkage and steering ratio above. Get pneumatic trail from TTC data as Mz/Fy in the linear region.

Import from Fusion 360

Three ways in
Option 1 · Recommended

Run the export script

  1. Put a construction point at each hardpoint of one front corner and name it LBJ, UBJ, OTR, ITR, WC, CP. Add LCA_F, LCA_R, UCA_F, UCA_R for bump steer.
  2. Download export_hardpoints.py.
  3. In Fusion: Utilities → Add-Ins → Scripts and Add-Ins → Create → Script (Python), name it export_hardpoints, click Edit, and paste the file over the template.
  4. Run it, save the CSV, and drop it on this page.
Option 2

Hardpoint CSV or JSON

Any file with a name and X, Y, Z per row. Names are matched loosely, so Lower Ball Joint, lca_outer and LBJ all work. Scalar rows like wheelbase and tire_radius are read too.

Option 3

Fusion parameters CSV

If your hardpoints live as user parameters (for example LBJ_x, LBJ_y, LBJ_z), export them with a parameter CSV exporter and drop the file here. The Unit column is respected.

Axes: Fusion is often Y-up. Set the CAD forward and up axes above before importing, or after importing and click Re-read last file. A right-side corner is mirrored automatically.

Note: the car centerline should sit at CAD lateral = 0. Ground comes from the contact patch, or from the wheel center minus tire_radius.
